# PaperXcel

PaperXcel 是一个面向科研阅读与文献管理的本地优先桌面工作区。它把 PDF 阅读、Markdown、笔记、全文检索、AI 助手、知识库和引文图谱放在同一个应用中，适合整理个人文献库、追踪证据链并开展文献综述。

## 主要功能

- **文献库**：拖拽或批量导入 PDF，通过 DOI、arXiv 等标识符添加论文，并使用文件夹、星标和归档整理资料。
- **阅读与笔记**：在 PDF 与 Markdown 阅读器之间切换，编辑并预览论文笔记，可选用 AI 生成或修复 Markdown 内容。
- **全库检索**：对论文正文进行 SQLite FTS5 全文检索，并结合轻量模糊匹配处理前缀、中文子串和少量拼写误差。
- **知识库**：汇总全部论文笔记，支持搜索、Markdown 源码编辑和渲染预览。
- **AI 助手**：连接 OpenAI-compatible API，围绕当前论文或整个资料库进行问答、摘要和研究辅助。
- **引文图谱**：结合 OpenAlex、Crossref 与 PDF 文末书目构建网络。首次显示与刷新时，节点自动聚拢并居中适配视野；圆点使用实时力导向与碰撞布局，拖动会推开邻居，松手后逐渐稳定。文献圆点按被引次数分为小圈（少于 100 次）、中圈（100–999 次）、大圈（1000 次及以上）。悬停展示论文信息，点击查看详情、摘要和参考文件。参考文件独立查询本文引用的文献，支持分批加载，不受图谱筛选限制。颜色区分参考文献与后续引用，二阶关系使用虚线和数字标记，画布箭头统一从被引用文献指向引用它的论文，即“二阶参考 → 一阶参考 → 目标论文 → 一阶后续引用 → 二阶后续引用”。兼容筛选、高亮、AI 分析、JSON 导出。二阶节点按完整引用路径筛选，必要的一阶节点共同计入显示上限。
- **图谱 AI 分析**：手动启动 agent，由模型制定计划，按 token 预算分批读取选中文献的完整已缓存网络，记录批次笔记并综合研究主题、关键工作、演进路径和待验证问题。分析不受圆点显示上限限制，不再按固定公式显示研究评分；实时展示阅读覆盖、模型计划、工具执行、研究发现和报告。每项发现附可点击的文献，演进路径必须有实际引用边支持。共用 273K 上下文边界与自动压缩，批次记忆可在压缩后再次读取。可随时停止并保留当前输出。研究对话由主进程持续保存到本地，刷新页面或重启应用可恢复；每轮独立保存问题、文献快照、阅读笔记、执行记录与报告。可沿用某轮的原始范围继续追问，或把该轮问题用于当前论文；同一快照复用阅读记忆，范围变化重新读取，旧报告的证据链接仍打开原始图谱。结论依据已有摘要、关键词及引用关系，缺失摘要不视为已读全文。
- **AI 论文发现**：选择一篇或多篇本地论文后手动启动，模型自主制定计划，按最多 10 页一批读取原始 PDF 正文，按科学内容设计和调整查询，通过 OpenAlex、Crossref、Europe PMC 检索，再阅读候选摘要并给出推荐顺序、与本地 PDF 页码对应的关联依据和证据局限。推荐只能来自实际检索且已读取的候选，不使用固定质量评分；没有合适论文时允许空清单。实时展示阅读、查询、筛选与报告，支持停止及对话恢复。无可读正文的 PDF 会明确说明，不冒充已读全文。
- **研究对话管理**：发现和分析页均可重命名、删除已保存的对话，也可在轮次选择框旁单独删除本轮。删除轮次后切换到相邻轮次；删掉最后一轮时保留对话名称，并清空报告和推荐。重命名保留各轮内容与文献范围；删除整段对话则清除全部轮次。所有变更在刷新或重启后仍然生效。执行中的对话需先停止或等待完成再管理。
- **论文搜索**：独立的普通检索入口，支持标题、DOI、研究问题、年份和来源筛选，通过三个来源并行检索，无需调用模型。结果分批显示，可停止并保留已取得的结果，继续加载复用已检索页面；合并重复书目，并可直接加入资料库。搜索与 AI 发现均已移除 arXiv 来源，聚合源返回的 arXiv 预印本同样过滤。
- **Zotero 同步**：支持本地 Zotero 与 Zotero Web API，同步论文元数据和 PDF。
- **预印本回退**：常规来源无法获取全文时，可按需尝试匹配 ChemRxiv 或 arXiv 预印本。

### 文献助手

Agent 使用模型原生工具调用。AI 根据问题自主制定通常 2–4 步的任务计划，通过 `update_plan` 更新步骤及状态，自行选择检索、阅读全文或按页阅读，并在同一会话中接收真实工具结果，直到生成最终回答。工具顺序、检索次数和计划内容均由模型决定；程序仅负责工具执行、参数校验、取消和运行预算。当前模型与服务端需要支持 Responses 或 Chat Completions 的原生工具调用。

界面显示模型实际给出的任务计划与公开工作说明，工具记录可展开查看。计划完成状态只来自模型更新，程序不会在回答结束时自动把步骤标为完成，也不会把等待时间或工具日志包装成思考内容。

回答按论文隔离并实时显示，支持页码证据、选区图片、附件以及编辑提问和重新生成。停止或连接中断时保留已收到的正文并标记未完成；向上阅读历史时暂停自动滚动，可点击“回到最新消息”恢复跟随。单篇和全库助手统一使用 273,000 tokens 的上下文预算，不按模型名称限制窗口；超过预算时自动压缩历史与工具结果，保留任务、计划状态、论文编号和页码证据，再继续当前任务。文本使用统一的 o200k_base 分词计数，工具运行过程中结合服务商实际输入用量校准；图片和文件在首次请求前使用估算。输入 `/compact` 也可主动压缩，完整聊天记录继续保留。

全库助手与单篇助手共用原生工具循环和流式请求生命周期。模型自行制定和更新计划，按需调用 `list_library`、`search_library` 和 `read_paper_pages`，支持重复检索、长页面续读和定位引用。用户固定的证据由本地论文重新读取；停止时保留已收到正文，不再通过固定检索模板模拟研究过程。

助手链路分为模型原生会话适配、工具循环（`paper-agent-runtime.ts`）、论文工具（`paper-agent-tools.ts`）、请求生命周期（`chat-run.ts`）、任务入口（`chat-service.ts`）、前端会话控制（`paperChatController.ts`）和流式视图（`ChatStreamView.tsx`）。正文使用增量与权威快照同步，最终结果、最新计划和公开工作说明统一落入本地历史；失败或取消的消息不会用作后续模型回答的已完成上下文。

### Markdown 重建与笔记

重新生成 Markdown 时，应用直接读取原始 PDF，每批合并最多 10 页作为一个 PDF 文件交给 AI；不使用 PDF.js 提取文字或旧 Markdown 作为输入。点击新生成会立即清空实际 `full.md` 和预览，随后持续写入并显示新正文。模型会跳过图片、References / Bibliography / 参考文献及 Nature Portfolio 等出版信息，保留正文中的公式、表格、文内引用和有实际内容的图注。Reporting Summary 及其统计、材料和方法等出版表单会从流式正文与已有缓存中排除。支持 Responses 和 Chat Completions 流式接口，需要配置支持 PDF 文件输入的视觉模型；接口不支持时会明确报错。

停止或断流时，新生成的文字保留在 Markdown 和草稿中，重新打开可查看。“重试此批”保留已经完成的批次并重新处理失败批次；点击“重建 Markdown”则清空全文从头开始。全部完成后更新生成记录和检索索引。AI 笔记的证据提取和最终综合均持续显示文字；中断草稿独立保存，可查看、继续生成或采用，原有笔记在完整生成成功或用户采用草稿时更新。

开发时运行 `npm run dev`，Electron 与 `http://localhost:5173/` 共用本地数据和真实后台接口。开发命令监听主进程及 preload 的代码变更并自动重启 Electron；普通浏览器通过仅限本机、同源的开发连接读取 PDF 和接收流式事件。生产版不启动此浏览器接口。

## 下载与安装

1. 打开 [Releases](https://github.com/Luedong-div/PaperXcel/releases/latest)。
2. 下载 `PaperXcel-1.1.0-win-x64.zip`。
3. 将压缩包完整解压到可写目录。
4. 运行解压目录中的 `PaperXcel.exe`。
5. 如需使用 AI 功能，在“应用设置”中配置服务地址、API Key 和模型。

## 从源码运行

### 环境要求

- Windows 10/11 x64
- Node.js `>= 22.12.0`
- npm

### 安装与启动

```powershell
git clone https://github.com/Luedong-div/PaperXcel.git
cd PaperXcel
npm ci
npm run dev
```

### 常用命令

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
npm run test:citation-graph
npm run dist:win
```

### 模块边界

- `src/main` 负责模型调用、工具执行和本地存储；`src/shared` 放跨进程契约与纯数据处理，界面通过 preload 接口访问主进程。
- 引文图谱的页面状态由 `CitationGraphWorkspace.tsx` 协调；范围筛选与本地论文匹配在 `citationGraphModel.ts`，圆点和连线在 `CitationGraphElements.tsx`，选择树和详情分别由 `CitationPaperSelector.tsx`、`CitationGraphDetails.tsx` 管理。
- AI Markdown 统一通过 `ChatMarkdown.tsx` 渲染，共用中文强调、公式、流式内容和 HTML 清理规则。
- 单元测试保留在对应模块旁。`tests/citation-persistent-research-smoke.mjs` 统一验证研究持久化、PDF 发现与工具参数纠正，使用临时资料库和模拟服务。

## 数据与隐私

- 论文、Markdown、笔记、索引、缓存和应用配置默认保存在程序同级的 `PaperXcel-Data`。
- 只有在用户主动配置并调用 AI、OpenAlex、Crossref、Zotero 等外部服务时，相关请求才会发送到对应服务。
